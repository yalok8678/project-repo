# 10-minute final presentation

1. Problem and users (1 min): collaboration breaks when people overwrite each other's work.
2. Product demo (2 min): create workspace, open shared page in two browsers, type simultaneously.
3. Architecture (2 min): React + TipTap, Yjs CRDT, WebSocket, Express, Prisma/PostgreSQL.
4. Conflict handling (1 min): explain CRDT updates and why edits converge without last-write-wins.
5. Features (1 min): presence, roles, comments, snapshots.
6. Challenges and trade-offs (1 min): room auth, persistence, access control, scaling boundary.
7. Test results (1 min): show measured latency and multi-browser test outcomes.
8. Next steps and individual ownership (1 min): Redis provider, deployment, security, performance.
